# TypeScript Senior Frontend Interview Kit

Target: **TypeScript 6.0**.

## First time
```bash
npm install
```

## Check the complete kit
```bash
npm run check
```

## Run any demo
```bash
npx tsx src/05_generics/03_Keyof_Generic.ts
```

## Study priority
1. Basics + functions + interfaces/types + unions/narrowing
2. Generics + utility types + advanced types
3. Strict safety + tsconfig + modules + async
4. Frontend/system-design patterns + interview coding
5. TypeScript 6.0/latest migration awareness

Every file has an interview one-liner at the top and commented runnable code.
