# QUICK USE

1. Open folder in VS Code.
2. `npm install` once.
3. `npm start`.
4. Use the left menu to select a topic.
5. Open the matching `.component.ts` file while screen sharing.
6. Say the top `INTERVIEW ONE-LINER`, then explain the commented implementation.

If your existing Angular project is older than Angular 22, keep this kit as a separate sibling project or upgrade before copying latest API files.
