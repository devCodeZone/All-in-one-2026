# Angular Interview Starter (Angular 22 standalone style)

## One-time setup before interview day
```bash
npm install
npm start
```

## During interview
- Start from `src/app/interview/problem-template.component.ts` for a blank task.
- Common examples are in `components/`, `services/`, and `utilities/`.
- Explain standalone components, signals vs RxJS, OnPush/change detection, reactive forms, DI, subscriptions/cleanup, interceptors/guards, accessibility and tests.

`package.json`, `angular.json`, and tsconfig files are strict JSON and cannot safely contain normal comments. Their explanation is kept here so the project remains runnable.
