# Quick Interview Use

1. Open terminal in this project.
2. Run `npm install` once.
3. Run `npm run dev`.
4. Use the left-side menu to open any React topic.
5. Open the matching JSX file in VS Code while screen sharing.
6. Read the `Interview one-liner` shown on screen and explain the comments in code.

For your existing React project:
- copy all numbered folders into `React/src/`
- optionally replace `App.jsx` + `index.css` with this kit's files
- keep your existing `main.jsx` if it already imports `App.jsx` and `index.css`

Recommended interview priority:
- Must master: useEffect cleanup, stale closures, batching, StrictMode, useMemo/useCallback, Context/reducer, fetch race handling, accessibility, performance, error boundaries.
- System design must master: Typeahead, Modal, Data Table, Optimistic UI, Design-System Button.
- System design understand well: Infinite Scroll, Toast System, Multi-Step Form, Auth Guard, Client Cache, Lazy Loading, Windowing, Error Handling.
