# React Interview Starter (React 19 + Vite 8)

## One-time setup before interview day
```bash
npm install
npm run dev
```

## During interview
- Use `src/interview/ProblemTemplate.jsx` for a blank task.
- Or open a prepared pattern in `src/components/` or `src/hooks/` for practice/reference.
- Explain state ownership, derived state, keys, accessibility, loading/error state, cleanup, and performance tradeoffs.

`package.json` must remain valid JSON, so it intentionally has no comments. Every source file contains explanatory comments.
