# Frontend Interview VS Code Kit

This folder is designed for a Senior Frontend Developer shared-screen coding interview.

## What is inside
- `Steps.docx` - exact setup and interview-time workflow.
- `system test coding.docx` - high-probability coding/system-test questions, answers, and oral one-liners.
- `JavaScript/` - Node/browser coding templates and common utilities.
- `React/` - Vite + React 19 starter with common interview components/hooks.
- `Angular/` - Angular 22 standalone starter with common interview components/services/forms.
- `Frontend-Interview.code-workspace` - open all three folders together in VS Code.
- `check-environment.bat` - quick Windows check for Node/npm/Git/VS Code.

## Important interview rule
Use these templates for practice and as a clean local starter only when the interviewer permits local VS Code. If the company gives HackerRank, CoderPad, CodeSignal, etc., use the platform they provide.

## Recommended preparation
1. Install Node.js 22.22.3+ so the Angular 22 project is compatible.
2. Run `npm install` once inside `React` and `Angular` before the interview.
3. Run each app once before interview day.
4. Do NOT keep AI assistants/Copilot enabled if the interviewer forbids them.
5. Share only the VS Code/app window if possible; close personal notifications.

## Fast opening
Double-click the `.code-workspace` file or run:

```bat
code Frontend-Interview.code-workspace
```
